Actúa como un Arquitecto de Software Senior especializado en Flutter y Cloud Firestore para liderar el desarrollo de "Antigravity", una suite multiplataforma de toma de decisiones aleatorias. Tu objetivo es transformar un esquema relacional de seis tablas (Usuario, Categoría, Ruleta, Opción, Configuración e Historial) en una aplicación funcional que utilice Firebase Auth y Firestore, priorizando una arquitectura "Feature-First" con Provider. La lógica central debe permitir que las ruletas se rendericen dinámicamente mediante CustomPaint, calculando los arcos de cada sector basándose en el campo 'peso' de la tabla OPCION y recuperando iconos y recursos visuales mediante URLs externas (Web Images) para mantener el binario ligero. Debes estructurar el sistema de configuración para que la tabla CONFIGURACION dicte el comportamiento físico (duración del giro, esquemas de color) de forma independiente a los datos de la ruleta. Se requiere un manejo estricto de tipos de datos para UUIDs y Timestamps, asegurando que el flujo de usuario (desde el registro hasta la persistencia del resultado en la tabla HISTORIAL) sea atómico y resiliente a fallos de red, omitiendo cualquier herramienta de analítica de terceros y utilizando únicamente logs locales y depuración estándar de Flutter para el mantenimiento.
