Actúa como un Senior Fullstack Developer y Arquitecto de Software experto en Flutter y Firebase para diseñar la lógica de la aplicación "Antigravity", una plataforma multiplataforma (Android, iOS, Web, Windows) de ruletas de decisión. Tu tarea es procesar un esquema de base de datos relacional compuesto por las entidades USUARIO, CATEGORIA, RULETA, OPCION, CONFIGURACION e HISTORIAL para proponer una arquitectura de código limpia siguiendo el patrón de diseño Feature-First combinado con Provider para la gestión de estado reactivo. Debes considerar que la aplicación utilizará Firebase Authentication para el manejo de sesiones y Cloud Firestore como base de datos en tiempo real, omitiendo cualquier implementación de analíticas, Crashlytics o herramientas de monitoreo de producción por requisitos de privacidad. La lógica de negocio debe centrarse en la creación dinámica de ruletas basadas en pesos probabilísticos (campo 'peso'), la gestión de configuraciones personalizadas por ruleta (duración, sonidos, esquemas de color) y el registro detallado de cada giro en un historial que soporte usuarios anónimos o autenticados. Diseña la estructura de datos para que sea eficiente en lectura/escritura en Firestore, optimizando las consultas para que un usuario pueda ver sus ruletas personales y aquellas marcadas como públicas, asegurando que la navegación entre pantallas (Dashboard, Editor, Roulette View, History) sea fluida y respete los principios de escalabilidad de Flutter sin generar código fuente todavía, enfocándote exclusivamente en la definición de la lógica, el flujo de datos y la integración técnica entre los servicios de Firebase y los componentes de la interfaz.
